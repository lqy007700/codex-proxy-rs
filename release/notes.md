# v3.50.0+lqy007700.v1

## 问题修复

- OpenAI WebSocket 新请求在发送前遇到瞬时建连失败时，按请求内建连预算和换号上限恢复；确认账号代理入口不可达后，本请求跳过使用同一入口的账号
- 原生续接在有效输出前遇到可安全重放且等待超限的容量拒绝时，允许在剩余换号预算内先迁移会话绑定，再通知客户端携带完整历史重试；不向替代账号发送当前增量输入
- 容量错误从 HTTP 响应头及 SSE、WebSocket 错误事件中移除旧账号的 `Retry-After` 和 `retry-after-ms`，保留原始诊断及关联 ID

## 管理端

- 账号默认按 OpenAI OAuth、OpenAI API Key、其他普通账号、保底账号排序，同类按 ID 稳定排序，手动排序偏好继续生效

## 升级事项

- 选择性合入上游 v3.50.0 的恢复修复，保留本分支的共享恢复预算、保底账号、会话与 Token 主绑定、可移植历史及管理端定制
- 无新增数据库迁移或配置项，账号额度 API 继续使用 `quotaLimits`；本版不包含上游额度桶预热及 URL 子路径部署功能
- 无状态码的流内 `invalid_request_error` 分类和独立窗口标题栏布局沿用已有实现
