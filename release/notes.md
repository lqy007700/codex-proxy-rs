- Claude Messages 支持从明确的会话请求头及新旧 `metadata.user_id` 格式建立账号亲和，保留可信调用方主绑定、请求恢复与保底规则
- 额度重置优先策略可独立配置 5 小时、周、月窗口系数，与智能调度分别保存；默认全零保持原排序，既有账号权重层和亲和策略继续生效
- 后台模型发现、目录导出、账号预热与管理端请求诊断使用全局客户端画像；官方版本检查改为每小时进行，固定版本不随后台检查改变
- 更新离线客户端版本资料，关联 ID 映射保留 UUIDv7 创建时间及复合窗口序号；继续保留安装 ID 请求头与正文一致、Key Seed 与固定安装身份覆盖

## 管理端

- 请求历史保留期支持超过 31 天，正整数范围为 1～4294967295；超长保留期下的清理与账号用量查询避免展开无数据的历史范围
- 支持兼容浏览器通过 HTTPS 或本机回环地址安装为独立窗口应用，包含标题栏与页面高度适配，使用时仍需联网
