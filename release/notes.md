# v3.41.2+lqy007700.v10

## 调度与账号亲和

- 按当前请求授权范围读取账号，批量获取冷却状态，并复用短时、有界的候选观测，减少重复调度查询
- 仅在安全新链确认主账号不可用或持续有效额度耗尽时自动改绑；繁忙、冷却、模型不匹配和未知额度继续保留主绑定
- 改绑前重新检查旧账号状态，保留普通／保底恢复预算、点数开关、账号模型映射、原生续接归属及 Guardian 独立并发池

## 停机与 OAuth 授权

- 正常关闭时取消本实例请求，有界释放普通池与 Guardian 池的账号租约，并为费用入队和后台写入保留收尾窗口
- 修复最后一个租约句柄释放时，异步清理任务可能被提前取消的问题
- OpenAI 重新授权更新本次登录的用户、工作区、邮箱和套餐，保留本地名称、代理、分组、账号用途、模型映射与点数设置
- 真实换号隔离 WS、Guardian、头像和持久续接状态，并清理旧身份的额度及重置卡计划；存在未决自动消费时拒绝换号
- 同身份重新授权未返回刷新令牌时保留旧值，真实换号不沿用旧身份令牌

## 代理

## 升级事项

- 本版不新增或改写数据库迁移，升级前仍请备份数据库
- OpenAI 或 xAI 的未完成 OAuth 流程若选择了 WS 连接上限非零的已保存代理，跨版本升级或降级后需重新发起授权
- OpenAI 重新授权真实换号后，旧身份的原生续接需使用完整输入重建；发生换号的凭据含 `oauth_identity_changed` 标记，不支持该字段的旧版本需恢复对应的数据备份后使用
