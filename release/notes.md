# v3.38.2+lqy007700.v1

## 单账号模型映射

- 账号管理的编辑弹窗支持“请求模型 → 上游模型”配置；账号映射优先，未命中时沿用全局映射，清空后恢复原有规则
- 目标直接作为最终上游模型，不继续套用其他映射，仍须通过所属 Provider 的模型能力、账号黑白名单、额度和租约检查
- Responses HTTP、WebSocket 和 Chat Completions 共用冻结映射；换号和保底使用新账号的目标，attempt 记录和费用按实际发送模型计算
- 普通目录按 Key 授权范围展示别名；原生目录保留完整模型对象、来源隔离与上游顺序，优先使用完整原生对象
- 原生增量续接遇到目标改变或无法确认原目标时要求完整历史重放；Images、独立 Search、Live 和管理员连接测试维持各自合同

## 上游 v3.38.2 同步

- 运行设置新增“上游重试等待上限”，默认 240 秒；超限时沿现有普通池与保底恢复规则处理，保留重放安全和账号归属约束
- Codex OAuth 上游 WebSocket 首次启用搜索时重建不兼容连接，保留搜索配置与完整输入；依赖原连接的增量请求要求客户端重放完整历史
- 收窄模型拒绝识别，只按结构化错误执行账号与模型冷却，避免将参数错误误判为模型权限问题
- 互联套餐摘要可从已保存额度补全，代理版本冲突返回前释放事务锁；同步适用依赖、Node.js 工具链与容器基础镜像更新

## 兼容与升级

- 新增迁移 `0044_retry_after_wait_limit.sql` 和 `0045_account_model_mappings.sql`，已有迁移按字节保留；已有账号映射默认为空，未配置时沿用原有行为
- 迁移在服务启动时执行；升级前备份数据库，回退时恢复匹配的应用版本与数据库备份，不能仅替换旧二进制或改写迁移 checksum
- 外部运行设置客户端和调用 `settings.load`／`settings.replace` 的插件需同步 `maxRetryAfterSeconds` 字段；调度候选的实际目标不同时，调度输入省略可选的 `model`，选号后的 attempt 使用实际目标
