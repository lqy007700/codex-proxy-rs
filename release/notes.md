# v3.57.2+lqy007700.v2

## 账号亲和

- 新增 New API Token 按请求次数切换账号的规则，默认关闭，默认阈值为 50；可在账号亲和页面配置全局规则或单个 Token 的覆盖，启用时需选择目标账号
- OpenAI 亲和设为优先或严格时，按身份来源、用户和 Token 独立计数。前 N 次按默认亲和选择账号，从第 N+1 次起使用目标账号，目标仍受当前 CPR Key 账号范围和账号状态约束
- 规则持久保存；主绑定和计数随亲和有效期到期，到期后重新计数。删除 Token 覆盖可恢复继承全局规则

## 升级

- 升级前停止写入并制作一致性数据库备份。服务启动时执行 `0065_newapi_token_affinity.sql`
- 应用迁移后，旧版本可能无法直接启动；需要回退时恢复与旧版本匹配的数据库备份
