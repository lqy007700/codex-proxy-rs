# v3.39.1+lqy007700.v9

## 加密历史恢复

- 修复开启“跨渠道聊天兼容”后，完整历史含压缩记录、业务密文或扩展条目时仍无法自动恢复的问题
- 上游明确返回 `invalid_encrypted_content` 且满足恢复条件时，在同一账号、当前会话内尝试一次恢复；只排除被拒绝输入中的加密推理项，保留其他历史条目的内容、ID 和顺序
- 增量续接遇到密文拒绝时，沿用客户端在当前会话重发完整历史的流程；缺少历史依赖、工具记录不完整或已经交付输出等情况仍阻止重放
- 诊断包补充条目类型和推理 ID、密文的独立指纹，便于分析历史差异，不记录原始敏感内容

## 移除 CPR Link 互联

- 移除节点互联发现、共享权限、远端账号池与额度展示，以及互联额度参与调度的能力
- OpenAI API Key 账号继续用于推理并展示本机累计用量，不再主动同步远端额度；原生 OAuth 额度查询与刷新继续保留

## 升级说明

- 相比 v8 无新增数据库迁移，已有迁移与 checksum 保持不变；历史互联数据保留，运行时不再使用
- 依赖 `/v1/cpr/link` 或 `peerSharing` 管理字段的外部集成需调整，升级后不再提供这些接口与字段
- 已保存的账号耗尽状态不会自动清除，确认额度恢复后使用现有账号管理操作处理
- “跨渠道聊天兼容”仍默认关闭，已有 Key 保持原设置；自动恢复需要客户端提供所需历史，无法还原缺失的聊天内容
