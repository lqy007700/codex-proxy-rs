# v3.33.0+lqy007700.v2

## 邮件告警

- 系统设置新增“告警通知”，支持配置全站模型请求失败率规则、SMTP 和接收邮箱
- 每分钟按请求完成时间评估滑动窗口，支持最小样本量、连续异常触发、持续提醒和恢复通知
- 按请求最终结果统计，排除主动取消、预热和内部调用，同一请求的内部重试不重复计数
- 提供当前窗口预览、测试邮件、最近告警与逐收件人投递结果，关闭管理页面后继续后台运行

## 投递与故障隔离

- SMTP 支持严格证书校验的 TLS 和必需 STARTTLS，密码不进入普通接口响应、审计或邮件错误输出
- 按收件人独立记录结果和重试，已成功地址不因其他地址失败重复发送，重启后沿持久化任务恢复
- 事件恢复后停止旧异常通知的后续尝试，在途发送成功保留结果，失败及过期未确认通知停止重试
- 检测和投递独立运行，数据库操作限制并发和超时，邮件故障不改变模型请求结果或单独导致健康检查失败

## 升级事项

- 新增数据库迁移 `0039_email_alerts.sql`，启动时创建告警配置、事件和投递表，已发布的 0001–0038 保持原样，升级前请完成业务备份
- 告警默认关闭，在管理端保存 SMTP 和接收邮箱后先发送测试邮件，确认投递结果后再开启
- 业务备份包含邮件配置和 SMTP 凭据，须按敏感数据保护；恢复业务归档后告警保持关闭，不重放旧通知
- 指标依赖异步请求记录，不覆盖执行前的鉴权、解析和准入拒绝，应用停机等存活告警仍需外部监控
