# v3.39.1+lqy007700.v4

## 账号亲和管理

- 新增“账号亲和”页面，可按来源、CPR Key、New API 用户、Token、主绑定账号和最近请求筛选已观测且未过期的 OpenAI 会话，分别查看主绑定账号和最近请求实际账号
- 支持清除绑定、排除原账号重选和指定目标账号，操作前生成精确预览，执行后返回逐项结果，并提供操作记录、失败重试及审计补写
- 管理操作校验绑定版本，避免覆盖并发更新；在途请求继续完成，调整在下一次安全选号时生效，原生续聊仍遵守原账号归属
- 用户、Token 和账号视图按当前页汇总，每次操作显式选择 1～200 个会话，不提供跨页全用户清理或永久账号偏好

## New API 可信身份

- CPR Key 可独立选择“直连 CPR Key”或“New API 可信转发”；共享 Key 按稳定来源、用户 ID 和 Token ID 隔离亲和、轮次关联、续聊及历史恢复状态，认证、预算、并发和分组权限仍由当前 CPR Key 控制
- 身份来源支持创建、改名、启停和跨 CPR Key 复用；同一 New API 实例轮换共享 Key 时可保留调用方归属
- 验证 `X-CPR-User-Id` 与 `X-CPR-Token-Id`，拒绝部分缺失、重复和非法值，并在最终出站时移除身份头；可显式允许不带双 ID 的独立探测请求，该请求不建立持久亲和且不能续聊
- 支持 HTTP JSON、SSE 和 Responses WebSocket；长连接后续轮次复核身份策略，New API 模式的 Live 与 Realtime sideband 暂不支持

## 请求记录与关联入口

- 请求记录保存入口冻结的调用方身份，身份筛选同时作用于明细和统计，可从请求详情、API Key 和账号页面进入对应亲和列表

## 升级说明

- 新增迁移 `0047_caller_identity.sql`，既有迁移保持原字节；已有 CPR Key 默认直连，保留原有绑定范围，旧请求身份保持未知，更新接口省略身份配置时保留原值
- 启用 New API 模式前，先创建稳定来源，并确认分发端使用认证结果覆盖双 ID；切换身份模式或来源不会迁移旧共享绑定，已有连接应重新建立
- 业务备份包含身份来源与 Key 策略，不包含临时亲和状态和操作日志；升级前制作一致性数据库备份，迁移后回退需恢复匹配版本与数据库备份
- 本地验收覆盖直连和模拟 New API 流程，尚未连接真实 New API 完成联调
