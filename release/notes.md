# v3.35.1+lqy007700.v2

## 跨渠道聊天兼容

- API 密钥增加“跨渠道聊天兼容”开关，默认关闭，可在创建和编辑时配置
- 开启后每次请求移除历史 reasoning 项并清除轮次续接状态，保留可见聊天、消息阶段、工具调用及结果的顺序和 ID，减少不同渠道无法校验旧推理密文导致的续聊失败
- 同时支持 OpenAI OAuth 与 API Key 上游的 HTTP/SSE 和 WebSocket；同渠道请求也会应用该策略，不继承历史内部推理状态，耗时、缓存和用量可能变化
- 增量续接请求要求客户端完整重放；只有密文的压缩历史、引用项和加密工具内容会明确报错，需要恢复可读历史或使用可读摘要开始新会话

## 升级事项

- 新增数据库迁移 `0042_client_key_portable_history.sql`，服务启动时自动执行；已有密钥保持关闭，旧客户端更新时省略该字段会保留原值
- 兼容模式需要客户端提供完整可读历史，网关不解密历史密文，也不保存整份聊天记录
