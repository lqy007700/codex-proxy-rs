# v3.35.1+lqy007700.v1

整合上游 `v3.35.1`（`d89db84a77d0143a91770b66bec47ab8f2e57a35`）的连接稳定性与错误处理修复，保留本仓库的请求恢复、账号调度及诊断合同

## 连接稳定性

- 修复 Responses WebSocket 慢速上传大消息时被心跳误判为失联的问题，探活包含实际入站字节进度；停传且不响应心跳的连接仍会超时回收
- OpenAI 会话亲和存储操作的等待预算由 100 毫秒调整为 500 毫秒，容纳短暂存储或调度抖动；策略排除记录保持独立的 100 毫秒预算

## 错误处理与诊断

- 客户端版本门禁拒绝返回 `400 Bad Request`，保留 `client_version_too_old` 和 `client_version_unavailable` 错误码，避免版本不符合要求时进入 WebSocket 回退路径
- 隐私规则拒绝请求时返回 `400 / privacy_policy_rejected`，仍在发送上游前终止，不自动重试或换号
- 修正 xAI 流式响应的错误类型识别，避免将顶层 SSE 事件类型用于上游错误分类
- 管理端自定义错误使用中文，模型 API 自定义错误使用英文；细化 API Key 参数校验及每日、每周费用限制提示，保留原始上游错误与内部诊断
- 系统更新与语音连接失败区分安全客户端提示和内部原因链，系统更新失败写入受控运维诊断

## 升级事项

- 相对 `v3.35.0+lqy007700.v1` 没有新增数据库迁移、插件协议或子模块版本变更，已发布迁移保持原样
- 依赖客户端版本门禁的调用方应通过上述错误码识别拒绝原因，不再依赖 HTTP 426
- 保留加密历史错误 `invalid_encrypted_content` 的 HTTP 409 映射及已开始 SSE 的流内错误边界
- 保留共享恢复预算、换号与保底账号、会话亲和、按账号隔离的 WebSocket 降级及二开发行版本排序规则
