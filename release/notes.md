# v3.30.13+lqy007700

## 修复与调整

- 合入上游 v3.29.6 的修复，保留现有容量错误有限重试与换号、账号级 WebSocket 降级与恢复、请求记录筛选等定制功能
- HTTP 明确未发送的瞬时建连失败在恢复时预留换号时间与次数，避免同账号恢复耗尽全部预算
- WebSocket 连接池根据实际建连结果更新熔断状态，避免将前台快速路径等待超时误计为建连失败
- 插件上游响应流不再受初始 RPC 时限约束，避免长时间流式响应被提前终止
- 业务备份使用压缩 SQL 归档，保留业务配置、账号、Key 和用量汇总，减少请求明细与诊断日志带来的备份体积；已有 .dump 备份仍按原格式下载
- 优化历史记录批量清理，减少大批量清理的耗时
