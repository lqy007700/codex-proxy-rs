# v3.39.1+lqy007700.v12

## 亲和管理操作优化

- New API Key 每行直接提供“设置主账号”，无需先勾选 Key 或切换批量操作下拉框
- 单个与批量设置共用账号搜索、变更预览和确认流程，勾选 Key 后显示批量入口，行内操作不改变已有批量选择
- “自动换一个账号”和“重置账号偏好”收进“更多”，明确系统重选其他账号与清除现有偏好的区别
- 设置与预览弹窗展示当前账号、目标账号及调用方来源，提交后显示“待切换至”目标账号，区分操作已保存与实际生效
- 改善弹窗阶段切换和请求失败后的键盘焦点，保留目录加载重试、绑定冲突提示及审计补写入口

## 升级说明

- 相较 v11 无新增配置或数据库迁移，不改变账号选择、临时分流与原生续接规则
- 指定主账号仍为优先使用的账号，后续符合条件的新请求生效，旧会话不迁移，目标不可用时仍可能分流
- 从 v9 或更早版本升级时仍需应用 `0048_retired_plugin_proxies.sql` 等尚未执行的迁移；升级前停止写入并制作一致性备份，跨迁移回退需要恢复匹配版本与数据库备份，不能仅替换旧二进制
