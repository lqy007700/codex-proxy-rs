# v3.41.2+lqy007700.v12

## 发行修复

- 修正阻断发行的上游错误分类合同测试，覆盖 HTTP/SSE 与 WebSocket 握手：400 历史缺失仍要求客户端完整重放，503 保持服务故障分类，并保留原始错误码
- 保留下列额度窗口上限、Cron 预热与 Messages 接入能力，运行时行为不变

## 通用额度窗口上限

- OpenAI OAuth 账号可在额度面板为账号级通用窗口设置 1–100% 的使用率上限，默认不限制
- 达到上限后暂停新请求，在途请求继续；本地暂停与真实耗尽、点数支出策略分别保存，缺失或迟到观测不推断为恢复
- 保留普通／保底用途、账号亲和、模型映射及二开请求恢复预算

## Cron 账号预热

- 运行设置使用部署时区中的单条五段 Cron，支持工作日、区间和步长表达式
- 预热只读取已保存额度，跳过真实耗尽及本地额度暂停的账号；继续保留跨重启执行游标和响应成功终态检查

## Anthropic Messages

- 接入 `/v1/messages`、`/v1/messages/count_tokens` 及 Anthropic 模型目录，可使用网关 Client Key 连接 Anthropic SDK 或 Claude Code
- OpenAI API Key 账号可选择 Responses 或 Messages 上游；Messages 使用 HTTP/SSE，旧账号默认保持 Responses
- Messages、Responses 和 Chat Completions 共用既有调度、映射、准入和结算；支持 Responses/Messages 双向转换，同协议保留原生扩展字段
- 客户端响应保留入口模型名，实际上游模型仍用于观测与价格；缺失用量和无法完整定价的费用保持未知
- 官方 Anthropic 地址使用原生输入计数，其他账号使用本地 BPE 估算；估算不发起上游生成，也不保证与上游账单一致

## 安全

- OpenSSL Rust 绑定固定为 `openssl 0.10.80` 和 `openssl-sys 0.9.116`，修复缓冲区溢出与字符串有效性安全公告，底层 vendored OpenSSL 源码版本保持不变

## 升级事项

- 新增 `0052`、`0053` 迁移，既有迁移不改写；升级前备份数据库，回退须恢复匹配版本与数据备份
- 迁移会关闭旧预热计划并清空时间配置，保留已选模型和执行游标；需要预热时填写 Cron 后重新启用
- 额度窗口上限默认关闭，不自动启用点数支出；协议切换保留账号本地设置并更新凭据版本
- 本版仅选择性移植上游 `v3.45.1`（`431992a7a43be32a0fad2fbc8a554732096fa299`）范围内的额度上限 `e3befd86`、Cron `620db1b8` 和 Messages `dd656651`，不是全量合并该版本
