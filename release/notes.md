# v3.39.1+lqy007700.v6

## 系统版本降级

- 「系统更新」增加「版本降级」入口，可选择当前运行版本之前、所选通道内的最近 5 个已发布版本，包含本仓库二开发行迭代号，仍受同一大版本和实验线限制
- 目标版本提供发布说明和发布页链接，缺少当前平台安装包或校验文件的版本不可选，不用更早版本补位
- 选择目标和最终确认时均提示降级风险，确认后复用下载、SHA-256 校验、备份与失败恢复流程，安装完成后显示待生效版本，由管理员手动重启
- 服务端在执行前重新核对目标范围，目标被删除或移出前 5 个版本时终止安装，不自动替换目标，降级前无法确认启用插件兼容时同样阻止安装
- 历史版本查询失败时清除旧候选并展示错误，支持重新检查，有待重启版本或正在执行系统操作时禁止再次安装

## New API 身份兼容

- 可信转发身份头缺失、部分缺失、重复或非法时，默认退回已认证 CPR Key 的直连范围，不会仅因身份识别失败拒绝请求，认证、预算、并发和分组权限继续执行

## 升级与降级说明

- **降级仅替换程序文件，数据库与配置不会回退**，旧版可能无法读取现有数据、启动服务或使用部分功能，降级前必须制作一致性数据库备份并确认目标版本兼容性
- 程序文件备份不能代替数据库备份，本版本不提供数据库逆向迁移或自动恢复
- 本版本没有新增数据库迁移，真实旧版与现有数据库的兼容性仍需由管理员确认
