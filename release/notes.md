# v3.30.6+lqy007700

## 新增功能

- OpenAI OAuth 账号在“额度重置”中新增“允许使用额度点数”开关，位于“自动使用重置卡”上方，默认关闭
- 关闭时，检测到套餐额度耗尽后停止调度该账号；开启后允许继续使用上游可用点数，套餐额度恢复后无需开启点数也能重新参与调度
- 点数设置与重置卡自动使用独立，重新导入、重新授权和额度刷新均保留设置；推理成功不会解除已确认的本地点数限制

## 升级事项

- 新增数据库迁移 `0036_account_credits_policy.sql`，增加账号点数设置并更新额度证据约束，既有迁移保持不变
- 存量账号和新账号默认关闭点数使用；依赖点数继续使用的账号升级后需手动开启
- 开关控制网关调度，不修改上游点数设置；额度观测可能延迟，已发送的请求仍可能消耗点数
- 提供 Linux amd64 归档与容器镜像，Docker 镜像标签为 `3.30.6-lqy007700`
