# v3.41.0+lqy007700.v1

## 上游功能整合

- 整合上游 v3.40.0 与 v3.41.0 的适用改动，保留可信身份转发、调用方亲和隔离、主账号绑定、独立恢复预算、账号模型映射及中文管理端
- Chat 兼容扩展至工具调用与结果、文件和音频输入、公开推理、图片、引用及 logprobs；JSON 与 SSE 共用既有交付校验与逐请求结算，图片预览或缺少最终结果不会被视为成功完成
- Key 编辑新增 OpenAI 安装 ID 配置，支持手填、生成和清除；安装 ID 仅影响对上游的请求画像，不改变本地调用方授权与隔离

## 账号与代理管理

- 账号编辑新增出口连接测试，可测试直连或受管代理，无需保存账号设置；禁用代理绑定按直连探测，批量编辑不执行出口测试
- 代理页面支持搜索、跨页选择并批量关联账号，一次最多分配 1000 个账号；失败后保留选择并可重试，仅更新账号的代理字段
- 模型允许列表增加独立清理入口，支持移除过时模型并防止误清空列表
- 改善 OAuth 结果通知、移动端登录布局、错误保护表单校验时机和主题预览的延迟加载与失败反馈

## 稳定性与诊断

- 修复大 SSE 请求回放和空闲 WebSocket 重连，保留取消、输出交付、工具副作用和截止时间等恢复边界
- 换号时清理不适用的客户端请求头；调整 turn state 保留与清理条件，继续校验 response ID 归属，避免跨账号或调用方复用状态
- 删除 Key 后保留历史账本，已有在途请求仍可完成结算；已删除 Key 不能发起新请求，重复结算保持幂等
- 修正 xAI 日用量和额度快照保留、账号模型成功率计算，避免失败恢复探测错误解冻账号
- 增强入口失败记录、可选请求检查和用量详情的错误恢复；接流就绪与后台 worker 健康分别判断
- 包含 main 尚未发版的 Token 名称单次解码修复，避免可信转发名称被重复 URL 解码；名称仍仅用于展示

## 升级说明

- 新增 `0049_preserve_client_key_ledger.sql`，保留已有 `0001`–`0048` 的文件字节与 checksum；迁移后删除 Key 不再级联删除既有预算窗口和费用事件
- 升级前停止相关写入、排空或核对在途结算，并制作一致性的完整数据库备份；精简业务备份不包含全部费用账本，不能代替此次迁移回滚所需的全库备份
- 跨迁移回退须恢复匹配的应用版本与数据库状态，不能仅替换旧二进制；恢复流量后产生的数据需要另行核对处理，不要修改 checksum 或删除迁移记录绕过校验
