# v3.55.2+lqy007700.v2

## 功能更新

- 账号分组支持配置协作子代理开关与模型白名单/黑名单限制，成员模型目录可直接勾选或快捷添加常用生图模型
- 账号级快速模式扩展超快速（`ultrafast`）档位，账号模型配置同步支持快捷添加常用生图模型
- API 密钥管理新增批量编辑功能，并新增近 7 天 / 近 30 天用量趋势与按模型统计弹窗
- 上游配置新增 Codex 自动审批专用审核模型开关（`codex-auto-review`）及 Codex OAuth 请求国家策略卡片
- 隐私策略支持工作区路径匿名化与分段匹配规则，保留原有隐私策略配置兼容
- 定时预热文案与账号重置预热加以区分，便于识别两类预热触发条件

## 问题修复与安全加固

- 备份存储配置不再在读取接口回传明文 `Secret Access Key`，改为返回配置状态并校验存储版本，防止并发覆盖或密钥暴露
- 运行设置引入独立乐观锁版本 `settings_revision`，避免后台配置并发写入互相覆盖
- 修复额度窗口恢复时长记录、同身份 OAuth 重新授权保留已有额度快照、停用 OAuth 账号继续刷新额度但保持不参与调度、WebSocket 控制连接绑定及未引用 `item_*` 历史项省略问题
- 更新 macOS 27.2.1 Codex CLI 预设与相关依赖及镜像基础版本

## 升级

- 启动时自动应用新增数据库迁移 `0061` 与 `0062`，现有二开功能（降智测试、账号级快速模式、代理附加测试地址、xAI 自定义 API Key、告警通知、N/M 恢复与保底、账号级模型映射与可信调用方亲和）均保持兼容
- 已有 S3 备份存储密钥继续有效；后续更新存储配置时留空 Secret 字段即可保留原密钥
