# v3.27.6+lqy007700

## 请求重试

- OpenAI 普通显式 `500` 支持安全重放条件下的自动恢复，与显式 `503`、无状态码且 `error.code=server_error` 的流内失败采用同一恢复策略
- 容量拒绝与上述服务故障共享请求内额外 5 次恢复预算：原账号额外重试最多 3 次，再逐次换号重试最多 2 次；换号、错误类别或传输变化不重置预算，既有路由和换号上限仍可提前终止恢复
- 本地退避基准为 500ms、1s、2s、2s、2s，每次另加随机等待；有效 `Retry-After` 优先，输出交付、副作用、续接、取消及超时限制保持生效
- 容量拒绝保留不受历史轮次失败标记抑制的行为；其他连接、凭据恢复及服务故障的同轮次抑制策略保持原规则

## 请求诊断

- 诊断导出包使用 `schemaVersion: 5`，包含同账号与换号重试判定、轮次失败抑制、安全重放证明、明确禁止恢复、中间件否决和剩余预算
- 普通安全重放路径记录未满足的静态门禁，便于区分输出屏障、账号绑定、发送不明确和预算耗尽；允许重试的决策与实际发起的 attempt 分别保留
- 导出字段经过类型与白名单校验，缺失或无效值为 `null`，继续省略原始错误、请求响应正文及任意事件数据；历史记录不会补造未采集的决策字段

## 升级事项

- 从 `v3.27.5+lqy007700` 升级无新增数据库迁移或配置项；容量拒绝的恢复预算按请求累计，不会在换号后重新获得同账号重试次数
- Docker 镜像标签为 `3.27.6-lqy007700`，继续提供 Linux amd64 归档与容器镜像
