# v3.39.1+lqy007700.v13

## New API Key 绑定管理

- `/affinity` 默认聚焦 New API Key 绑定，移除顶部搜索、多余汇总和行内会话信息；保留名称、Token 与用户来源、主账号、最近请求账号、准入与到期时间，以及分流和待执行状态，改善窄屏阅读
- 更换主账号仍需选择目标、预览和确认，保留绑定冲突检查与操作审计；“查看请求”按调用方身份查看请求记录，不再局限于最近请求或最近账号
- 来源、操作历史与直连会话收进“更多管理”；页面不查询会话数量或进行中请求，也不自动轮询

## 可选转发 Token 名称

- 支持可信 New API 请求通过 `X-CPR-Token-Name` 转发 Token 名称，使用原始 UTF-8、去除首尾空白，原始值最多 256 字节；重复头、空白、非法编码、控制字符或超长值均忽略
- 缺失或无效名称保留未过期绑定已有的有效名称，无名称时显示 `Token #ID`；兼容已有绑定与操作快照
- 名称仅用于展示，不参与鉴权、绑定、账号选择或续接隔离，不转发给上游；New API 需在认证后覆盖填写该可选请求头

## 升级说明

- 相较 v12 无新增配置或数据库迁移，不改变账号选择、临时分流与原生续接规则
- 指定主账号仍为优先使用的账号，后续符合条件的新请求生效，旧会话不迁移，目标不可用时仍可能分流
- 从 v9 或更早版本升级时仍需应用 `0048_retired_plugin_proxies.sql` 等尚未执行的迁移；升级前停止写入并制作一致性备份，跨迁移回退需要恢复匹配版本与数据库备份，不能仅替换旧二进制
