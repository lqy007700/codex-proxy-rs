# v3.34.0+lqy007700.v1

## 插件兼容与请求恢复

- 插件启动、重启、更新和回滚统一检查宿主兼容性，不兼容实例保持未启动，保留配置、绑定和私有数据
- 管理员可确认一次兼容性提醒，确认绑定宿主、实例版本和制品摘要，仅对本次启动有效；损坏包、清单、RPC 或平台不兼容不能绕过
- 单次受管 HTTP 429 在撤销 RPC 回调、封存发送观测后判断重放资格，继续受现有恢复预算与安全门禁约束；已有输出、续接材料、额外调用及发送结果不明不新增重放资格

## 模型目录与账号选择

- SDK 新增 `model_catalog v2`，支持账号范围内的独立适配模型，并继续支持 v1；原生完整模型对象优先
- 实际选号、亲和、同账号恢复、轮换和保底使用路由收窄后的账号范围，并共同遵守 Key 权限与模型能力限制
- 模型目录成功读取后被账号政策全部过滤时返回空列表，新增 GPT-6.1 Terra 标准、Flex、Priority 及长上下文计价

## 搜索与管理界面

- 账号、Key、用量和运维错误统一使用字面量包含搜索，保留账号内部／上游 ID 字段和用量时间搜索
- 账号批量操作移入更多菜单，简化账号组筛选，调整用量页窄屏日期控件排列，保留请求明细与统计概览的信息顺序
- 各额度窗口按自身剩余比例着色，剩余不足 30% 显示警示、不足 10% 显示危险状态

## 稳定性与升级事项

- 加密历史与目标模型不匹配时返回 HTTP 409，便于客户端识别历史冲突
- 升级 Zstd 安全封装，保持底层版本与压缩级别；修复 Windows 备份暂存文件编译，保留 Unix 权限及取消清理
- 本版无新增数据库迁移，已发布的 0001–0039 及冻结摘要保持原样；升级前请完成业务备份
- RPC 保持 v7，保留邮件告警、普通／保底账号、共享恢复预算、WS 降级恢复、Chat 兼容、请求审计和诊断包 v6
- 不兼容插件在宿主重启后会重新检查；需要继续尝试时须重新确认，升级前请检查所用插件的宿主要求
