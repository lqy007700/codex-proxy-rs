- 增加只读接口 `GET /v1/cpr/link`，支持按 Client Key 权限公开预算、匿名账号池、额度窗口及模型观测
- Key 编辑增加互联开关及账号池、额度与模型、套餐分布权限，既有和新建 Key 默认不启用共享
- 启用共享必须显式选择非空分组，推理与共享范围同时收窄到分组中的直连 OAuth 账号，不递归转供 API Key 中转账号

- 共享池可以包含保底账号，但不传递本地调度角色，各节点仍按自身恢复阶段和预算执行，不合并跨节点重试次数

## 模型资格与稳定性

- 原生 OpenAI 与 xAI 选号结合有效目录和本地模型政策筛选，权重、亲和及固定账号不能绕过模型资格，受管适配器继续使用自身模型合同
