# v3.47.0+lqy007700.v1

## 调度与请求恢复

- 智能调度支持分别设置 5 小时、周、月额度重置权重；旧配置继续使用原评分公式，只有显式启用才切换分窗口模式
- 新会话成功准入后才推进轮询游标，已有亲和、可信主绑定、严格续接及恢复轮询保持原有行为
- `NO_MORE_RETRY` 停止当前账号的重试与传输恢复，后续换号、保底或返回错误仍受二开 N/M 预算及重放安全门禁限制

## 模型目录与传输

- 聚合当前 Key 可访问的 OAuth 账号模型目录，保留账号来源、模型映射和排除规则；成功目录持久化恢复，请求不等待上游刷新
- Responses 目录支持版本协商；刷新失败或返回 304 时保留上次成功目录，账号删除与身份变更使旧目录失效
- WebSocket 按当前连接握手声明的消息上限检查最终编码字节数；完整历史超限可回退 HTTP，精确原生续接要求完整重放，保留账号、会话及恢复代次隔离
- 原生 Responses 请求保留显式服务档位，Messages 诊断读取客户端显式推理强度；保留既有输出 Token 预算与协议适配

## 管理与统计

- 账号预激活支持多条五段 Cron，同一分钟多条命中只执行一次；保留部署时区、持久游标、额度暂停和成功终态判断
- UI 升至 v0.11.0，修正自定义主题色、底色、浮层及设置加载失败提示，并沿用定制账号、请求记录页面和中文布局
- 缩小统计重算中间集，减少无关列物化；可选事务级统计 `work_mem` 默认不配置，沿用 PostgreSQL 设置
- 管理端诊断补充错误来源及上下游状态，保留 scope、失败 Token／费用、自定义统计和请求健康字段
- 修复更新时跨目录移动只读目录的权限处理，备份及回滚保留原权限

## 升级事项

- 选择性对齐上游 v3.47.0，保留二开恢复预算、普通／保底用途、点数策略、亲和、模型映射和发行平台范围，并非完整合并上游历史
