# v3.27.4+lqy007700

## 请求重试

- OpenAI 普通显式 `503` 支持自动重试，不再要求错误码为 `server_error`；容量、额度和限流等特殊分类沿用各自策略
- 原账号额外重试最多 3 次，再逐次切换其他账号重试最多 2 次，请求内共额外重试最多 5 次；账号不足或既有预算耗尽时提前停止，不回用已排除账号
- 保留指数退避、随机等待和 `Retry-After` 优先级；继续遵守输出交付、发送状态、副作用、续接、取消、超时及客户端同轮次重试限制

## 管理端

- 请求明细在结果旁显示总尝试次数，包含首次尝试；首次成功请求不额外显示次数
- 精简请求明细列宽，将请求时间移至账号前，User-Agent 最多显示两行并保留完整悬停提示
- 账号状态列提供调度开关，保存期间禁用重复操作，失败后恢复原状态
- 仪表盘优先展示请求健康时间线与账号概览

## 发行与升级

- 失败发行可在核对来源版本、提交、检查和产物后复用已验证构建，重新执行打包、签名和发布
- 从 `v3.27.3+lqy007700` 升级无新增数据库迁移；继续提供 Linux amd64 归档与容器镜像
- Docker 镜像标签为 `3.27.4-lqy007700`，在线更新来源继续使用 `lqy007700/codex-proxy-rs`
