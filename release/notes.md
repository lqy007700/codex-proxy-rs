# v3.39.1+lqy007700.v3

## 重试与保底

- 初始账号尝试次数与换号重试次数独立配置：`recoveryAttempts=N` 包含首次请求，`recoveryRotationAttempts=M` 统计其他普通账号的合计尝试次数，换号不重置 N，最后保底最多尝试一次
- N=3、M=0 时全部失败顺序为 `A-A-A-保底`；N=2、M=1 时为 `A-A-B-保底`；N=3、M=2 时为 `A-A-A-B-C-保底`，仅 B 可用时为 `A-A-A-B-B-保底`
- 初始账号业务重试在无有效上游等待建议时固定等待 1 秒，有效 `Retry-After` 仍优先；进入其他账号或保底阶段立即重选，首次成功路径不新增等待
- 业务恢复独立于 `maxAccountRotations`；安全重放、已交付输出、续接归属、取消及截止时间限制继续生效，请求总路由次数仍最多 32 次，并为保底预留最后一次机会

## 运行设置

- 亲和策略增加“换号重试次数”，默认 1，设为 0 时初始账号尝试耗尽后直接保底；原换号限制更名为“其他恢复换号上限”，用于连接、传输及续接等其他恢复路径
- 保存时校验 N 为 1～31、M 为 0～30，且 N+M 不超过 31；在途请求沿用入场时冻结的配置
