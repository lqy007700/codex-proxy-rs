# v3.57.0+lqy007700.v1

本版选择性移植上游 `v3.57.0`（`6950c02ee4`）的 OpenAI 在线设置和 Antigravity 系统指令修复。

## OpenAI

- 平台设置支持在线调整数据驻留、账号路由和 Responses WebSocket 连接池参数，保存后对新请求生效。
- 未设覆盖的字段沿用 YAML，可单独省略路由请求头。已有连接保留原寿命与空闲期限，连接池开关继续由 `openai.ws_pool.enabled` 控制。

## Antigravity

- 常规生成和 Token 计数把平台提示放在客户端指令之前，保留项目规则、工具说明和其他系统指令。

## 升级

- 本发行线追加数据库迁移 `0064`。现有部署可继续使用原 YAML 和管理 API 请求格式，升级前请保留一致性数据库备份。
