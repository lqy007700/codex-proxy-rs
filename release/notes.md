# v3.35.0+lqy007700.v1

## 账号错误保护

- 新增可配置的错误保护规则，可按平台、上游状态码、错误码、错误类型和错误信息匹配失败
- 支持失败阈值、滑动计数窗口、冷却时长和恢复探测；账号详情展示命中规则，过期反馈不能覆盖管理员恢复操作
- 保护默认关闭且无预设规则，不自动转换旧容量冻结设置，也不再自动下调账号并发上限

## 协议与连接

- Chat Completions 增加 `max_tokens`、采样参数、`verbosity`、缓存、`moderation` 和 `user` 支持；同时提供两种 Token 预算时优先使用 `max_completion_tokens`，保留严格参数校验和现有 JSON/SSE 交付边界
- 改善 WebSocket 下游关闭、上游 Pong 和连接池空闲清理，保留按账号及会话隔离的传输降级与手动恢复
- 完善官方 Codex 客户端版本门禁及续接推理强度观测；管理端生成的 Codex 配置包含模型目录地址与语音控制地址
- Images 与 Live 共用账号套餐资格检查，Live 不再选用 Free 账号

## 统计与管理端

- 响应性能增加负载视图，展示平均并发、峰值并发、准入和选号等待 P95；保留原有耗时、速率、调度、容量和覆盖率字段
- API Key 账号的 Dashboard 身份下方显示备注，密钥明文操作区分加载状态并取消过期结果
- 保留中文界面、账号搜索字段、原始 User-Agent、请求审计范围、业务恢复预算、普通与保底账号策略及邮件告警

## 升级事项

- 新增迁移 `0041_account_error_protection.sql`，已发布的 `0001`–`0040` 保持原样，升级前请完成数据库备份
- 升级后错误保护处于关闭状态，请在系统设置中重新配置规则；已有冷却时间与账号并发上限保留，管理员可按需恢复账号或调整上限
- 插件模型目录仅接受 `model_catalog v2`，使用 v1 的插件需采用匹配 SDK 重建；不兼容配置、绑定与私有数据保留
- 数据库迁移移除了旧容量冻结设置列，回退旧程序须配合升级前的数据库备份
