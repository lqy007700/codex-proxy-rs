# v3.53.0+lqy007700.v6

## 问题修复

- Responses 回退到 HTTP/SSE 后，HTTP 客户端继续使用需要完整重放的旧响应 ID 时，会收到 `previous_response_not_found`，可带完整历史重试
- OpenAI OAuth 额度查询确认访问令牌被撤销后，将该令牌标记为过期，仍有效的刷新令牌可继续续期。模型目录刷新会显示凭据冲突或账号存储故障
- 账号额度预测在重置时间抖动时保留周期内的已记录用量，疑似进入新周期时暂停估算，等待独立读数确认

## 升级提醒

- 从 `v3.53.0+lqy007700.v3` 或更早版本升级时，已有 OpenAI 账号默认「跟随客户端」，旧分组设置不会自动迁移。此前依赖分组关闭 Fast 的，请将对应账号设为「关闭」后再恢复流量
- 分组管理 API 不再接收或返回 `fastMode`，请改用账号更新 API
