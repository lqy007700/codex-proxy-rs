# v3.27.3+lqy007700

## 使用统计

- 成功记录与错误排查合并为请求明细，默认显示所有请求，可筛选成功或错误；错误范围包含失败、取消和未完成请求
- 请求列表显示结果与错误摘要，统一详情保留错误诊断、原始错误详情、尝试链和诊断导出
- 成功请求、总 Token、缓存 Token、平均耗时、请求健康、热点诊断、响应速度和成本效率统一放入「统计概览」，默认折叠
- 移除侧边栏的主题设置入口，保留深浅色切换

## 上游配置

- 「请求位置覆盖」新增「解析出口位置并填入表单」按钮，沿用代理编辑页的交互与加载状态
- 解析网关服务器直连出口，成功后填入国家、地区、城市及 IANA 时区并启用覆盖，点击「保存基础设置」后生效
- 位置解析失败或 IPv4 / IPv6 出口时区冲突时保留原表单，允许继续手动填写

## 发行与升级

- 仅发布 Linux amd64 归档与容器镜像，适用于 Ubuntu 等兼容部署环境
- 从 `v3.27.2+lqy007700` 升级无新增数据库迁移，继续通过管理端「下载并更新」和「立即重启」完成升级
- 请求明细筛选不改变用量汇总、费用及账号用量的统计口径；请求重试与账号切换策略保持现有行为
- Docker 镜像标签为 `3.27.3-lqy007700`，在线更新来源继续使用 `lqy007700/codex-proxy-rs`
