# v3.30.14+lqy007700

## 修复与调整

- 合入上游 v3.29.7，保留现有容量错误有限重试与换号、credits 开关、账号级 WebSocket 降级与恢复、请求记录筛选等定制功能
- 更新 follow-redirects、rustls-webpki 和 webpki-roots，修复重定向与证书信任相关安全问题
- 插件 HTTP、模型 request/attempt 中间件的响应流在建立后不再沿用初始处理期限，避免长时间响应被提前终止
- 插件模型调用与受管 HTTP 请求统一使用有效正文大小配置，默认 64 MiB，避免固定正文上限提前拒绝；在途模型请求沿用冻结预算
- 插件模型调用保留客户端 IP 与 User-Agent，补全响应头、HTTP 版本、trailers、WebSocket 原文及失败尝试的上游观测
- 后台任务在依赖检查或实际工作成功后恢复健康状态，避免依赖恢复后健康检查仍持续返回 503
- 编辑账号时默认选中已绑定的出站代理，未修改选择时保留绑定，主动选择直连时才清除绑定
- 优化 Windows Codex 版本检查，避免扫描整个 MSIX 包耗尽下载预算

## 升级事项

- 相较 `v3.30.13+lqy007700` 没有数据库迁移，无需新增配置项
- 插件 RPC 协议升级至 v5，upstream_adapter 能力升级至 v4；已有插件须使用当前 SDK 重新编译并打包，不能仅修改清单版本
- `responsesMaxDecompressedBodyBytes` 同时约束插件受管 HTTP 的实际出站正文；超限返回 413 且不发送请求，大正文插件需核对该配置
- 提供 Linux amd64 归档与容器镜像，Docker 镜像标签为 `3.30.14-lqy007700`
