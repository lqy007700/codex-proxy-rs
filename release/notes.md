# v3.39.1+lqy007700.v10

## New API Key 账号亲和

- 可信 New API 转发按来源、用户和 Token 保留主账号偏好，同一 Key 的不同窗口与无会话标识请求共用偏好，更换 CPR 接入 Key 不改变该身份
- 优先与严格模式下，主账号不支持当前模型、繁忙、额度耗尽或冷却时允许临时分流并保留主绑定；主账号永久失去资格或移出当前授权范围时，下一次符合条件的普通新链可迁移主绑定
- 原生增量、重放归属、显式固定账号与严格模式后代跟随继续优先；同账号重试、换号、恢复及保底沿用已有预算，不将临时账号写为主账号，跨渠道历史继续遵守原有安全恢复条件

## 亲和管理

- 默认按 New API Key 展示主账号、最近请求账号、待执行动作及目标，支持状态筛选、行内更换和按本页用户或账号批量操作
- 支持重置主账号偏好、更换或指定主账号，先预览再执行，绑定版本冲突时不覆盖新状态
- 目标暂不可用时保留待执行操作，本次请求按原偏好使用可用账号；重试与原生续接不消耗 Token 管理指令
- New API 会话归属只读，可与 Key 主绑定互相定位；直连 CPR Key 保留按会话管理，窄屏同样展示主账号与亲和状态

## 移除网关插件系统

- 移除插件运行时、SDK、CLI、管理接口与页面，以及发行物中的插件分发依赖
- 保留插件归档表，运行时不再加载其中的代码与配置；原生账号、分组、Key、用量及请求基础能力继续使用

## 升级说明

- 相比 v9 新增 `0048_retired_plugin_proxies.sql`，已有迁移与 checksum 保持不变；删除出站代理时仅清空旧插件归档上的代理引用
- 升级前停止写入并制作一致性备份；应用迁移后不能仅替换旧二进制回退，需要恢复匹配版本与数据库备份
- 依赖插件接口、命令或插件执行链的集成需先调整，本版不再提供这些能力
- Key 亲和仅对已识别的可信 New API Token 生效；宽松模式不使用该主绑定，认证、额度、并发与账号范围仍由 CPR Key 决定
- 亲和列表仅包含已观测且未过期的绑定，用户与账号汇总限当前页；最近请求账号表示准入观测，不代表上游成功或实时健康
- 所有授权账号都不可用或历史不足以安全恢复时，仍可能按原有规则返回错误；改绑主账号不迁移旧响应与连接状态
