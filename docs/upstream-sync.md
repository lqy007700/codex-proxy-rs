## 继续保留的二开差异

以下是明确保留的行为，不因存在上游差异就自动覆盖；改变这些选择前先列出影响供用户确认

| 范围 | 本仓库保留内容 |
| --- | --- |
| 失败重试 | `RetryThenRotateAccountWithBudget`：容量拒绝及可恢复的 `500`、`503`、无状态码 `server_error` 共享请求内额外 5 次预算，原账号额外重试最多 3 次，再逐次换号最多 2 次；换号、传输或错误类别变化不重置预算 |
| 重试安全与诊断 | 保留重放资格、已交付输出、续接、发送状态、取消、截止时间、外部副作用和插件约束；保留阻断原因与剩余预算，实际重试须由后续 attempt 证明 |
| 管理端请求范围 | 默认所有请求，保留请求结果和尝试次数；错误筛选包含失败、未完成和取消，但保留各自状态；Key 错误筛选仍只含失败与未完成 |
| 使用统计布局 | 请求明细置顶，统计概览在下且默认展开、可折叠；所有请求、成功、错误筛选仅显示图标 |
| Chat Completions | 通过 Responses 提供兼容入口，保留完成 Token 预算适配 |
| 请求表格 | 紧凑列宽、靠前的请求时间、请求结果列和请求 ID 搜索 |
| 错误与诊断交互 | 快捷提示、实际尝试次数、页面诊断时间线和关联请求；采用后端导出，同时保留页面查看能力 |
| 账号调度入口 | 状态列旁的直接开关，不改为只在操作菜单中切换 |
| 点数使用设置 | OpenAI OAuth 账号在“额度重置”中单独开启，存量与新账号默认关闭；关闭时套餐耗尽即停止调度，额度刷新、重新导入和重新授权保留设置；边界见[账号额度说明](api.md#账号能力导入与-oauth) |
| 账号并发明细 | 保留当前占用数量、并发上限与手动刷新，同时保留自动刷新 |
| 概览与主题入口 | 请求健康时间线和账号概览靠前；侧边栏隐藏主题设置入口，主题页面与路由保留 |
| 出口探测 | 保留检测反馈及显式代理连接失败后不回退直连的边界 |
| 安装、更新与发行 | 使用本仓库的安装源、更新源、镜像地址和版本身份，保留同版本构建产物恢复入口 |
| 发布平台 | 仅发布 Linux amd64；未采用上游的 Linux arm64 与 macOS arm64 发行配置，不代表源码不能在这些平台构建 |
| 协作规则 | 保留本仓库的 `AGENTS.md`、`CONTRIBUTING.md` 和 `.agents` 规则，规则更新单独评估；未采用 Dependabot 修改工作流的保护例外 |

| --- | --- |

| 工具链与子模块 | Node.js `26.12.0`、Rust `1.99.1`；UI 和插件按宿主锁定提交同步，不自行追踪各子仓库最新分支 |

## 每次同步时维护

1. 核对工作区与远端，记录当前发行 tag、提交和目标上游稳定 tag；只读分析冲突和完整差异，分别列出采用、保留和待选项
2. 对照二开差异表逐项追踪调用链，核对自动合并的代码，不能只检查冲突文件；需要改变保留项时先取得用户选择
3. 检查当前已部署迁移的编号与 checksum，新增迁移只追加；同时核对 API、插件合同、子模块和构建工具链
4. 按影响验证请求恢复、页面交互、数据库升级和发布流程；通过、失败、跳过和未执行分别报告，不把旧版也存在的失败计为通过
5. 就地更新本文的基线、能力表、保留项和待选提交，移除已失效待办；逐版本的发行变化留在对应 tag 的 `release/notes.md` 与 Release，不在本文追加历史章节
6. 按本轮授权分别完成本地修改、提交推送、发布或部署；用户要求停止跟踪发布时，交付任务链接，不把成功触发当作产物发布成功
